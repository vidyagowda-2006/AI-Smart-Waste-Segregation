# AI Smart Waste Segregation System

## Project Description
An AI-based waste classification system using TensorFlow and Machine Learning. It classifies waste into five categories: Glass, Metal, Organic, Paper and Plastic.

## Project Files
- dataset – Training and testing images.
- src – Python source code.
- model – Trained AI model.
